# shared/

The cross-domain web layer — the eighty-one files that serve two or more features rather than belonging to one: the shared drawings (`components/`), the insights display config (`config/`), the cross-domain hooks (`hooks/`), the snapshot clients and stores (`lib/`), the dictionaries (`i18n/`) and the UI kit (`ui/`). A file lives here only when its importer census spans multiple domains or tools (the audit's shared-vs-domain driver); single-consumer files belong to their feature or tool folder, and legacy-only files belong to `features/insights-legacy/` (deviation D4). The paths that read into this tree — the Persian-copy SOURCES, the narrator-vocabulary generator, the selfcheck workflow, `gates.mjs`'s layer1 path — update in the same commits as the Phase 2 moves. Created empty in M1; the files arrive in Phase 2.
