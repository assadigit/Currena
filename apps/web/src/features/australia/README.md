# features/australia/

The `/australia` domain — fourteen files when Phase 3 (M5) lands them: `AustraliaPage`, `AustraliaTierCards`, `AustralianMarkets`, `MoneyPanel`, the `au-markets/` subfolder (briefing + shared helpers), `lib/markets-au` (the AU markets snapshot client), `australia-board-copy`, `australia-tiles`, `australia-backtest-core` and their tests (copy-pin, tiles, backtest). The NZX50 rider on the AU board makes this folder the code home the asia-pacific mirror card borrows (the documented edge), and `au-markets/shared.ts` also serves `AsiaNzx50Card`.
