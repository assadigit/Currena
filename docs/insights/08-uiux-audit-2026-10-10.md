# Insights UI/UX audit — 2026-10-10 (owner-triggered)

The owner reviewed https://currena.ir/#/insights and reported two symptoms:

> "everything is written with black color, instead different shades of grey,
> red and green can be used appropriately. also there is low typographic
> hierarchy, every heading is screaming and grabbing the eye."

This document records the audit, the root cause found underneath symptom 1,
and the fixes (round R29). Fixed the same day; every fix is browser-verified
in en/fa × light/dark × 1280/375.

## Findings

| # | Finding | Root cause | Severity |
|---|---------|------------|----------|
| A0 | **`text-[var(--type-label)]` / `text-[var(--type-caption)]` never set a font-size.** Tailwind 4 cannot know whether an opaque `var()` in `text-[…]]` is a length or a colour and resolves it as **colour**. The generated rule was `.text-\[var\(--type-caption\)\]{color:var(--type-caption)}` — an invalid colour that falls back to *inherited* at computed-value time. | Tailwind arbitrary-value ambiguity | Critical (silent since I15) |
| A1 | **The ink ramp never rendered.** Because the type-size classes sorted *after* the colour utilities in the stylesheet, their invalid `color` declaration won the cascade and erased `text-[var(--color-text-secondary)]` → every label/caption rendered in primary ink. This is literally the owner's "everything is written with black color". | cascade fallout of A0 | Critical |
| A2 | The measured ink step primary→secondary (#2C3E50 vs #46505C, 12.6:1 vs 8.2:1) is perceptually near-identical — even where secondary did render there was no visible ramp; no tertiary grade existed for meta (timestamps, sources, kickers). | token layer | High |
| A3 | Red/green lived only in the small status chips; the STATUS WORDS (verdict "Stressed/Cautious/Relaxed", gauge step words, "n of m need attention" counts, price "expensive/cheap") all sat in navy. | component layer | High |
| A4 | Monotone weights: page h1 800, section h2 18px/800, group questions and card titles 14px/800 — six heading levels competing at the same volume (the owner's "every heading is screaming"). | component layer | High |
| Deltas (7-day/30-day changes) stay **neutral by decision** — R5/R9: direction is carried by number+arrow, never by colour (colour-blind readers, RTL mirror). Unchanged. | — | decision |

## Fixes (R29)

### 1. The cascade bug (A0/A1) — `length:` hints

Every `text-[var(--type-label)]` → `text-[length:var(--type-label)]` and
`text-[var(--type-caption)]` → `text-[length:var(--type-caption)]`
(128 occurrences, 18 files). The hint forces the font-size interpretation,
so the type scale finally computes AND stops emitting a bogus colour
declaration. No visual regressions: the sizes that now apply are exactly the
sizes the design always specified (label 14px, caption 12.5px).

### 2. Ink ramp (A2) — tokens

- `--color-text-secondary`: #46505C → **#56616E** (6.3:1 on white) — a step
  the eye can actually see below primary.
- NEW `--color-text-tertiary`: **#6B7683** light (4.7:1) / **#8291A5** dark
  (5.0:1 on cards) — captions, timestamps, sources, kickers, disclaimers.
- Dark `--color-text-secondary` unchanged (#9AA8BC, already a visible step).

### 3. Status words speak in status ink (A3) — helpers

New in `config.ts` (G5 preserved — every tinted word sits beside an icon, a
meter or a number, never colour alone):

- `stepToneClass(step)` — verdict/gauge step words: relaxed → green,
  cautious → **new `--color-status-watch`** (#9C5019 light / #FBB48C dark),
  stressed/alarmed → red. Applied to the hero verdict word, the hero gauge
  readings, and every group's step word.
- `attentionToneClass(warnings)` — "n of m indicators need attention" lines:
  red while n > 0, green only when clear.
- `bandToneClass(band)` — PRICE position words only: cheap → green,
  expensive → red, typical → neutral. Indicator position words stay neutral
  (R5: "unusual" is notable, not good or bad).

### 4. Typographic hierarchy (A4) — type roles

New utilities in `index.css`; 800 weight now belongs to NUMBERS only:

- `.type-section` 17px/700 (was text-lg/800) — the five section h2s +
  details-panel title.
- `.type-question` 15px/600 (was 14px/800) — group questions, connection
  card titles, pinned strip.
- `.type-kicker` 11.5px/600 uppercase tertiary — GLOBAL/AUSTRALIA, NEEDING
  ATTENTION NOW, SEARCH/FILTER/DOWNLOAD, HISTORY, signals footing labels.
  `letter-spacing` scoped to `html:not(:lang(fa))` (Arabic script joins
  letters — never letter-spaced).
- Page h1 24px: 800 → 700.
