# LICENCES.md — the licence register (v3: RULES.md M-9 / RISK_REGISTER.md)

The machine-readable twins: `packages/insights/src/sources.ts`
(`SOURCE_RISK_REGISTER`: level L0–L3, owner_accepts, the M-6 `enabled` kill
switch, method M1–M5, runtime, terms lines, date read, attribution) and
`packages/insights/src/licences.ts` (the display gate:

`data/indicators.json` + `data/indicator-audit.json`; the T-15/T-26/T-30/T-31
gates enforce them.

by the T-15 mode gate — an unverified source can never appear in public mode.
**Panic switch:** `ACCESS_MODE=private` (or `PANIC_PRIVATE=true`) re-arms the
gate on every Insights data endpoint within one refresh cycle (M-5).

v3 F-01 pass, plain honest requests, `CurrenaDashboard/1.0 (+…)`). Venue

**The mechanism, one paragraph:** every display verdict lives in the licence
register (`packages/insights/src/licences.ts`, `publicDisplayOk`) and flows
into the generated `data/site-mode-overrides.json` (the public-mode hidden
set) via `pnpm registry:generate`; the T-15 gate, the serve-time filter and
the projection all read that ONE generated file. Hiding any class again is
one register edit + one regen + one deploy — no card code changes. The
panic switch for the whole page is `ACCESS_MODE=private` (or
`PANIC_PRIVATE=true`), which re-arms the gate on every Insights endpoint
within one refresh cycle (M-5). Nothing on this list is hidden today
except the four no-data ids; the table exists so the owner can act in
future WITHOUT an archaeology dig — the acceptance trails (who accepted
what, when, on which recorded answer) all cite the README's decision tables
in `docs/specs/gold-meter-gapfill/`.
