## Declined (with reasons — do not silently "fix")

| # | Quirk | Reason declined |
|---|---|---|
| Q1 | Native selects truncate long names at 375 px | The full-names caption sits directly beneath the select and the OS picker shows full names; truncating is the intended compact surface. Restyling native pickers would add fragile custom dropdowns for no readability gain. |
| Q2 | fa amount placeholder renders a slash-shaped decimal separator (U+066B Arabic decimal separator) | This is the app-wide fa convention (documented; the i18n corpus and tests pin it). Changing it per-control would break en/fa consistency, and the copy corpus is a protected surface. |
| Q10 | Live-rates KOSPI card shows a yellow (not red) bear chip | Deliberate two-tier status design (§8.2): red is reserved for needs-attention; yellow reads "unusual, not alarming". Reverting would re-introduce the retired single-tier "Alert" pattern. |
| Q11 | Flap-board digit glyphs render ASCII (not Persian) digits in fa | The flap boards use a digital segment font that has no Persian digit glyphs; substituting text digits would break the flip-board visual. Persian digits appear in every data line elsewhere (R22 parity holds). |
| Q12 | Live-rates tile alignment drifts when long titles wrap to two lines | Only reachable with unusual locale fallback fonts; the masonry-style grid absorbs one-line drift and real titles wrap consistently. A hard line-clamp would truncate currencies the owner wants visible. |
| Q13 | fa Insights header repeats the date in the sub-line | Intentional copy design (the sub-line is the "as of" phrasing that includes the date for scanability). Copy corpora are protected; a visual de-dup would need a wording change the commission excludes. |
| Q14 | Insights floating action button overlaps the last card's edge at some scroll positions | The FAB is a deliberate floating pattern with its own shadow/elevation; it never overlaps interactive elements (verified — the pointer target under it is always dead area). |
