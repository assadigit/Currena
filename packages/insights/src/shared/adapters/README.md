# shared/adapters/ (engine)

The cross-domain + infrastructure adapters: `fred` (66 series across five domains — D9), `yahoo` (the prices board + brent gapfill + usdaed + peaks), `worldbank` (the Pink Sheet — gold column + the commodities columns), `goldapi` (gold/silver/platinum/copper/btc spots — D2), `monthly-indexes` (GPR five domains + EPU/TPU + GSCPI — D10), `oecd` (CLI usa/deu/chn + NZL), `derived` (the ~170-id assembly hub — cannot split), the rung orchestrators (`collect`, `rung2`(+inputs), `rung4`(+inputs)), `snapshot`(+gates) (the snapshot assembly + projection), `fetch-policy` (the ONLY fetch path), `types` (the FetchDeps/AdapterError contracts), the format readers (`biff`, `xlsx`, `zip`), `manual` (the data/manual loader) and the barrel `index.ts` — plus the cross-adapter test files, which split to follow their subjects at move time.
