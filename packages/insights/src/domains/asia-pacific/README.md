# domains/asia-pacific/

The Asia-Pacific domain's adapters: `nbs` (china-pmi, china-cpi, china-property-investment, china-steel-output), `mof` (jgb-10y) and `imf-cpi` (japan/korea/india CPI via the IMF SDMX 3.0 dataflow), with their co-located tests. The NZ mirrors (nz-short-rate, nz-10y) stay in the shared oecd/fred bulk adapters.
