# domains/australia/

The Australia domain's engine: the `markets-au/` subfolder (the AU markets board job — the 18 ASX indices + the S&P/NZX 50 rider: compute, definitions, job, providers, run, store) plus the adapters `abs` (ABS SDMX), `abs-au` (the monthly AU series) and `rba` (the RBA tables), with their co-located tests. The NZX50 board's code home is here by D-17/BD-S21b — the web asia-pacific mirror card borrows it through the API surface.
